# おじパン もぐもぐ だいさくせん 🐼🎋

娘の描いたキャラクター「おじパン」(デザイン:ほのか)が主役の、スマホブラウザで遊べるスコアアタックゲーム。

- **3D版**: https://hugofukuhara.github.io/ojipan/
- **2D版**: https://hugofukuhara.github.io/ojipan/2d/
